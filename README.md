# Workforce Management System

A full-stack employee management application with CRUD operations. The frontend is built with **React (Vite)**, the backend with **Spring Boot**, and data is stored in **PostgreSQL**. It is deployed on an **AWS EC2** Ubuntu instance.

**Live demo:** http://<EC2-PUBLIC-IP>:9090
(Hosted on a free-tier instance, so it may be offline at times.)

## Features

- View all employees in a table
- Add, update and delete employees through modal dialogs
- Live filtering in the browser by:
  - Employee ID
  - Name
  - Department
  - Salary range
  - Joining year and month
- "No employees found." message when a filter has no match
- Validation for required fields, email format and non-negative salary
- Duplicate email check (case-insensitive) that returns `409 Conflict`
- Not-found and error responses returned as JSON
- Employee IDs generated by a PostgreSQL sequence
- Success and error notifications in the UI

## Architecture

```
Browser
  -> React frontend (Vite)
  -> Fetch API calls
  -> Spring Boot REST controller
  -> Service layer (validation and business logic)
  -> Spring Data JPA repository
  -> PostgreSQL
```

During development, the frontend runs on Vite's dev server and calls the backend at `http://localhost:9090`. In production, the React build is copied into the backend's `static` folder, so the app runs as a single JAR.

## API Endpoints

| Method | Endpoint | Description |
|---|---|---|
| GET | `/get-employee` | Get all employees |
| GET | `/get-employee/{id}` | Get one employee by ID |
| GET | `/search-by-name?name=...` | Search employees by name |
| POST | `/add-employee` | Add an employee |
| PUT | `/update-emp` | Update an employee |
| DELETE | `/delete-employee/{id}` | Delete an employee |

## Run Locally

**Prerequisites:** Java 21, Node.js, PostgreSQL

**1. Database**
```
CREATE DATABASE employees;
```
Load the sample data:
```
psql -U <your_user> -d employees -f backend/backup.sql
```

**2. Backend**
The app reads these environment variables (defaults to `localhost:5432/employees`):
```
DB_URL=jdbc:postgresql://localhost:5432/employees
DB_USER=<your_user>
DB_PASSWORD=<your_password>
```
Then run:
```
cd backend
./mvnw spring-boot:run
```
The API starts on port 9090.

**3. Frontend**
```
cd frontend
npm install
npm run dev
```
To point the frontend at a different backend, set `VITE_API_BASE_URL` (see `frontend/.env.example`).

## Build a Single JAR

1. Build the frontend:
   ```
   cd frontend
   npm run build
   ```
2. Copy the contents of `frontend/dist` into `backend/src/main/resources/static/`.
3. Build the JAR:
   ```
   cd backend
   ./mvnw clean package
   ```
4. Run it:
   ```
   java -jar target/<jar-name>.jar
   ```
   Open http://localhost:9090.

## Deployment on AWS EC2

1. Launched an Ubuntu EC2 instance (t3.micro).
2. Added inbound Security Group rules for SSH (port 22) and the app (port 9090).
3. Copied the JAR and a `pg_dump` backup to the instance with `scp`.
4. Installed Java 21 and PostgreSQL on the instance and restored the data.
5. Started the app in the background with environment variables:
   ```
   nohup java -jar <jar-name>.jar > app.log 2>&1 &
   ```
6. Checked logs with `tail -f app.log`.

## Tests
