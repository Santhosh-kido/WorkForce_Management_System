# Workforce Management System (WFMS)

A responsive React (Vite) frontend for workforce directory and employee management.

## Features
- **Branding**: Workforce Management System (WFMS)
- **Live Filtering**: Dropdown filter bar supporting All Employees, By ID, By Name (debounced via API), By Department, By Salary range, and By Joining Date (Year starts-with and Month select).
- **CRUD Operations**: Add, update, and delete employees with modal confirmations.
- **REST API Integration**: Direct integration with Spring Boot backend via `src/api/employeeApi.js`.

## Getting Started
```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```
